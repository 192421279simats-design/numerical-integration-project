Mathematical Background

Numerical Methods Explained

01
Trapezoidal Rule
∫ ≈ (h/2)[y₀ + 2y₁ + 2y₂ + … + 2yₙ₋₁ + yₙ]

Approximates the area under a curve by summing trapezoids formed between consecutive data points. Error is of order O(h²) — reliable for smooth, well-sampled functions.

02
Simpson's 1/3 Rule
∫ ≈ (h/3)[y₀ + 4y₁ + 2y₂ + 4y₃ + … + 4yₙ₋₁ + yₙ]

Fits quadratic polynomials through groups of three points, yielding a much higher accuracy of order O(h⁴). Preferred when the function is smooth and the number of intervals is even.

03
Composite Integration
∫ₐᵇ f(x)dx ≈ Σ∫ₓᵢˣⁱ⁺¹ f(x)dx

Both rules are applied in composite form — the interval [a, b] is subdivided into n subintervals, dramatically reducing truncation error compared to applying each rule only once over the full range.
